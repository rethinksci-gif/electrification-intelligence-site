[Open the full 24-week learning pathway →](roadmap/index.md)

At 4–6 hours per week, progress from data and units to markets, solar-storage, industrial heat, grids and materials. Includes weekly tasks, GitHub tutorial links and six stage gates. All tasks are still planned; the twelve modules below are not yet published as lessons.

## Learning route

This is a plan, not a completed curriculum. Each session should produce one reusable explanation, one example with explicit assumptions and one open question.

| Module | Related thesis | Suggested output |
| --- | --- | --- |
| Electricity markets | H1 / H5 | Separate wholesale and delivered factory prices |
| Solar economics | H1 / H2 | Explain curtailment and capture prices |
| Battery storage | H2 | Separate power, energy, duration and service cost |
| Grid architecture | H5 | Map the connection from generator to factory |
| Industrial electricity | H4 | Compare costs under matched operating conditions |
| Heat pumps | H3 / H4 | State temperature lift and COP boundaries |
| Industrial heat | H4 / H6 | Compare temperature, heat transfer and material needs |
| EVs and charging | H3 / H5 | Connect sales, stock and actual use |
| Power electronics | H2 / H6 | Connect conversion efficiency, cooling and components |
| Critical minerals | H6 | Separate intensity, substitution and recycling |
| Electrification materials | H6 | Trace components to material properties |
| Industrial geography | H4 / H5 | Compare tariffs, connection and supply chains |
