[查看完整 24 周学习计划 →](roadmap/index.md)

按每周 4–6 小时，从数据与单位逐步进入市场、光储、工业热、电网与材料。计划包含每周任务、GitHub 教程入口和六个阶段验收标准；所有任务仍是计划；下表十二个模块尚未作为课程发布。

## 学习路线

以下是计划，不代表已完成课程。每次学习只需形成一个可复用的概念解释、一个注明假设的算例和一个未解决问题。

| 模块 | 关联假设 | 建议学习产出 |
| --- | --- | --- |
| 电力市场 | H1 / H5 | 区分批发电价与工厂到户电价 |
| 光伏经济性 | H1 / H2 | 解释弃电与捕获电价 |
| 电池储能 | H2 | 区分功率、容量、时长和服务成本 |
| 电网架构 | H5 | 画出电源到工厂的接入链 |
| 工业用电 | H4 | 建立同工况的电气成本比较 |
| 热泵 | H3 / H4 | 说明温升和性能系数的适用条件 |
| 工业热 | H4 / H6 | 比较温度、热传递与材料要求 |
| 电动汽车与充电 | H3 / H5 | 连接销量、保有量和实际使用 |
| 电力电子 | H2 / H6 | 连接转换效率、散热与组件 |
| 关键矿产 | H6 | 区分用量、替代和回收 |
| 电气化材料 | H6 | 形成组件到材料性能的证据链 |
| 工业地理 | H4 / H5 | 比较电价、接入与供应链约束 |
