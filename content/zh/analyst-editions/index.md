已发布专刊保留研究截止日期、证据状态和关键不确定性。

## 每期专刊包含什么

每期回答四个问题：哪些观测变了、哪些判断没变、最强反证是什么、下一步查什么。

| 部分 | 内容 |
| --- | --- |
| 核心判断与假设看板 | 主要结论，以及 H1–H6 各项假设的当前状态 |
| 信号与拐点观察 | 最重要的变化、一个看似重要但可能只是噪音的信号，以及是否越过了某个阈值 |
| 深度分析 | 逐步拆解一个机制 |
| 材料与地区 | 系统变化如何传导到组件、材料和具体地区 |
| 等待的证据 | 什么证据会改变判断 |
| 证据附录 | 每条引用记录的来源、日期、观测期和状态 |

每个数字都附有来源和观测期。不熟悉的编号见[术语与指标](../methodology/glossary/index.md)；深入调查在[专题研究](../research-sprints/index.md)中继续。
