专刊用简写引用指标编号、证据编号和项目阶段，本页逐一说明。定义依据项目已复核的指标目录；某项定义已验证，不代表它的每一个观测值都已验证。

## 证据标签

| 标签 | 含义 |
| --- | --- |
| **V** / 已验证 | 项目已在记录范围内核对来源主张或计算。经过核对的企业主张仍然是企业主张。 |
| **C** / 候选 | 已提取、尚未复核。提取置信度不等于证据置信度。 |
| 解读 | 分析师根据证据作出的推断。 |
| 假设（H1–H6） | 待检验的命题，并写明什么会改变判断。见[假设追踪](../../thesis/index.md)。 |
| `EI-E…` | 已验证证据记录的编号，在各期专刊的证据附录中可查。 |
| `EI-P4-E…` | Phase 4 试点产生的候选记录编号。 |

成组列出的编号（例如同一来源的两条记录）不是相互独立的佐证。完整的阅读说明见[研究方法](../index.md)。

## 日期

- **研究截止日期：**专刊汇集证据的最后日期。
- **观测期：**数字所度量的时期，例如 2024 年或 2025 年下半年，通常早于截止日期。
- **来源日期：**发布方发布或修订该来源的日期。
- **快照日期：**项目抓取并核对来源副本的日期。

因此，一期 10 月发布的专刊可能主要依据 2024 年的观测，专刊会明确说明这一点。

## 项目阶段

- **Phase 3 基线：**当前专刊所用的、有来源快照支撑的已验证观测集。
- **Phase 4 试点：**一次离线重放，用 Phase 3 已抓取的来源快照重新提取主张，以测试证据采集流程。它没有产生晚于 Phase 3 的新发现。其记录在人工复核前一律为候选，重新提取也不构成独立佐证。

## 关键术语

| 术语 | 本站含义 |
| --- | --- |
| 清洁增长比率（CGR，K03） | 清洁发电（可再生能源与核电）的年度增量，除以系统供给需求的年度增量。低于 1 表示清洁增量未能覆盖新增供给。 |
| 供给需求 | 报告口径的国内总发电量加净进口，不是计费用电量，也不是峰值负荷。 |
| band-IC 电价 | Eurostat 统计的年用电量 500–2,000 MWh 非居民用户电价，不含增值税及可抵扣税费。它是参考价，不是某家工厂的实际电价。 |
| 铭牌能量 | 储能的额定能量容量（MWh 或 GWh），不是可用能量、输出功率或年吞吐量。 |
| 有用热 | 实际交付给工艺的热量。比较电加热与燃气加热，应匹配有用热，而不是燃料投入。 |
| COP | 性能系数：热泵在给定温度条件下，每单位电力所输出的有用热。 |
| 同等服务 | 在产出、时段、可靠性和地点都相同的前提下比较不同技术。没有这一前提的成本比较只是输入，不是结论。 |
| 材料链 | 系统变化 → 技术 → 组件 → 材料 → 性能要求 → 机会或风险。 |
